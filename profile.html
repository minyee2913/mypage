2019년 마인크래프트 맵 제작으로 개발을 시작했고, 2020년부터 Minecraft Bedrock RPG 서버 Luminous Wanderlust를 지금까지 만들고 있습니다.

선린인터넷고등학교에서 대회·해커톤·동아리 프로젝트로 Unity 게임을 꾸준히 만들었고, 지금은 KAIST 새내기과정학부에 다니며 1인 팀 네로폰으로 로그라이크 덱빌딩 액션 RPG IGNOTUS를 개발하고 있습니다 (2027년 상반기 출시 목표).

액션 전투와 멀티플레이(LAN·전용 서버·Steam P2P, Photon)부터 모바일 출시, 게임 서버 개발까지 직접 다뤄 왔습니다.

2026년부터는 Claude Code 같은 AI 코딩 에이전트를 실제 개발에 깊게 쓰고 있습니다. 발!도!!는 바이브 코딩으로 Google Play 출시까지 했고, 에디터와 서버에 에이전트를 직접 연결하고 에이전트가 지킬 작업 규칙과 반복 작업용 스킬을 만들어 혼자서도 큰 프로젝트를 진행합니다.

AI 활용 개발

AI에게 코드를 맡기는 데서 그치지 않고, 에이전트가 게임 에디터와 서버를 직접 다루게 연결하고, 지켜야 할 규칙과 검증 절차를 문서로 만들어 결과를 믿을 수 있게 합니다.

  1. 바이브 코딩으로 출시까지

    발!도!!와 제발 꺼져 용사야는 바이브 코딩 프로젝트다. Unity MCP로 에디터와 연결한 에이전트가 코드를 쓰고 기획·방향·검증을 맡았다. 발!도!!는 지하 1000층, 최소 풀이 솔버, 광고 연동까지 갖춰 2026년 8월 말에 시작해 10월에 Google Play에 출시했고, 제발 꺼져 용사야는 약 나흘 만에 Android 빌드를 만들었다.

    발!도!! →제발 꺼져 용사야! →

  2. 에디터에 에이전트 연결 (Unity MCP)

    Unity MCP로 Unity 에디터와 AI 에이전트를 연결해, 에이전트가 프로젝트를 직접 다루며 작업하게 한다. 발!도!!, 제발 꺼져 용사야, IGNOTUS 프로젝트에 설정되어 있다.

    IGNOTUS →

  3. 에이전트 작업 규칙 문서화

    Luminous 서버 저장소에 에이전트용 규칙 문서를 두었다. 라이브 서버에서 재시작·접속 테스트 금지, 업스트림 병합 검증 절차, 프로토콜 변경 절차, 증거 없이 '고쳤다'라고 보고하지 않기, 측정 수치는 조건과 함께 보고하기 등을 정해 두고 에이전트와 일한다.

    Luminous Wanderlust →

  4. 게임 편집기를 에이전트가 직접 조작

    루미너스 런처 안의 UI 디자이너와 스토리 편집기에 AI 에이전트용 로컬 HTTP API를 만들었다. 에이전트가 편집기를 직접 조작해 UI와 스토리 장면을 만들 수 있고, 127.0.0.1 전용·토큰 인증·웹 페이지 요청 차단으로 안전하게 열었다.

    루미너스 런처 →

  5. 반복 작업을 스킬로 자동화

    Claude Code 스킬을 직접 만들었다. 실행 중인 서버에 콘솔 명령을 보내고 로그를 읽는 스킬, 로컬 서버에서 실제 플레이를 녹화하고 편집해 장비 소개 영상(롱폼·숏폼·썸네일)을 만드는 스킬이 있다.

    Luminous Wanderlust →

  6. 검증까지 맡기는 개발

    이 포트폴리오 사이트는 Claude Code와 함께 다시 만들었다. 정적 생성 구조, 모든 페이지를 HTTP로 확인하는 검증 스크립트, 게임별 연출과 효과음을 에이전트와 만들고, 화면 겹침과 프레임까지 자동 측정으로 확인했다.

    myPage (이 포트폴리오 사이트) →
