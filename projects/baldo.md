# 발!도!!

> Slash!!

> 한 번의 발도로 이동과 공격을 함께 하는 1000층 액션 퍼즐 (Google Play 출시)

검을 발도하면 그 방향 끝까지 돌진하며 스친 적을 모두 벤다. 정해진 발도 횟수 안에 층의 모든 적을 처치하며 지하 1000층까지 내려가는 모바일 액션 퍼즐 게임.

- 페이지: https://human.minyee2913.net/projects/baldo
- 카테고리: 게임 개발
- 개발 기간: 2026.08
- 개발 상태: 출시
- 플랫폼: Mobile (Android)
- 장르: 액션, 퍼즐
- 팀 구성: 1인 개발
- 게임 엔진: Unity 6 (URP 2D, Pixel Perfect)
- 사용 언어: C#
- 프레임워크 / 라이브러리: Google Mobile Ads (AdMob), Input System, NUnit (Unity Test Framework)
- 주요 기술: 바이브 코딩 (AI 코딩 에이전트 + Unity MCP), 엔진 독립 순수 C# 규칙 코어, IDDFS 최소 풀이 솔버, 솔버 검증형 절차적 레벨 생성 (1000층), 상태 기반 실시간 힌트, 히트스톱·화면 흔들림 타격감, 보상형·전면 광고 연동

## 프로젝트 소개

**바이브 코딩**으로 혼자 만들어 Google Play에 출시한 모바일 액션 퍼즐 게임이다(현재 버전 1.7). Unity MCP로 에디터와 연결한 **AI 코딩 에이전트**가 코드를 쓰고, 기획과 방향, 플레이 검증을 맡아 2026년 8월 말에 시작해 10월에 출시했다.

'발도 한 번 = 이동 + 공격'이라는 규칙 하나로, 남은 횟수 안에 모든 적을 벨 경로를 찾는 퍼즐을 만들었다.

퍼즐 규칙은 Unity에 의존하지 않는 **순수 C# 코어**로 분리했고, 실제 플레이·조준 미리보기·힌트·자동 풀이·검증이 모두 **같은 시뮬레이터 하나**를 호출한다.

지하 1000층은 손으로 그린 튜토리얼 4층을 빼고 모두 **에디터 도구로 생성한 뒤 솔버로 최소 풀이를 검증**했고, 층마다 허용 발도 횟수를 그 최소값에 맞춰 정했다.

## 게임 플레이

- 방향을 한 번 탭하면 돌진 경로가 점선으로 미리 보이고, 같은 방향을 한 번 더 탭하면 발도한다. 8방향(대각선 포함)으로 벨 수 있다.
- 발도하면 벽이나 보드 끝, 정면 방패, 버튼에 막힐 때까지 돌진하고, 경로 위의 몬스터에게 피해를 준다.
- 부서지는 벽, 경로를 꺾는 거울, 같은 방향으로 이어지는 포탈, 닿으면 죽는 가시, 발도 횟수를 1 돌려주는 충전 아이템, 연결된 폭탄을 터뜨리는 버튼(3×3 범위) 같은 기믹이 층이 내려갈수록 하나씩 등장한다.
- 몬스터는 일반(체력 1), 정면을 막는 방패, 체력 2의 중갑, 발도할 때마다 정해진 길을 따라 움직이는 이동형, 2×2 크기의 대형이 있다.
- 모든 몬스터를 처치하면 클리어, 발도 횟수를 다 쓰거나 가시에 닿으면 실패다. 막히면 광고를 보고 지금 상태에서의 힌트를 받을 수 있다.

## 설계 / 패턴

- 어셈블리 분리: Core(엔진 참조 없는 순수 C# 규칙·솔버) / Runtime(화면·입력·저장·설정) / Editor(층 생성기·검증 도구) / Tests
- 규칙 단일화: 발도 시뮬레이터 하나를 실제 플레이, 조준 미리보기, 힌트, 솔버, 검증기가 모두 공유한다
- 상태 표현: 층 상태를 비트마스크와 상태 키로 표현해 탐색 중 빠르게 복사·비교한다
- 데이터: 층 1000개를 ScriptableObject 에셋으로 두고 층 데이터베이스에서 불러온다
- 장면 구성: 씬과 UI를 코드(빌더)로 만들어 수동 배치 없이 재현할 수 있게 했다

## 핵심 구현 기능

### 하나의 시뮬레이터로 통일한 발도 규칙

돌진·피해·기믹 판정을 한 곳에만 구현하고, 게임의 모든 기능이 그것을 호출한다.

**구현 목적**: 플레이 화면, 조준 미리보기, 힌트, 자동 풀이가 서로 다른 규칙으로 계산하면 '힌트대로 했는데 안 풀리는' 버그가 생긴다. 규칙을 한 곳에만 두어 이런 불일치를 원천적으로 막았다.

**동작 방식**

- 발도 시뮬레이터가 돌진 경로, 벽·방패·버튼에서의 정지, 거울 반사, 포탈 이동, 가시 사망, 충전 아이템, 폭탄 폭발, 대형 몬스터의 1회 피격을 모두 처리한다.
- 규칙 코어는 **Unity를 참조하지 않는 순수 C# 어셈블리**라서 에디터 도구와 단위 테스트에서 그대로 돌릴 수 있다.
- 무한 반복을 막기 위해 이동 단계 상한과 반복 감지를 두었다.

**사용 기술**: C#, Assembly Definition, 비트마스크 상태

### 1000층 절차적 생성 파이프라인

'정답 경로를 먼저 만들고 그 위에 퍼즐을 채우는' 방식으로 지하 1000층을 생성하고 솔버로 검증한다.

**동작 방식**

- 층 번호에 따라 보드 크기(7×7 → 최대 11×13), 목표 최소 발도 횟수(2 → 9), 몬스터 수(3 → 최대 30), 벽 비율, 특수 몬스터 비율이 커지는 난이도 곡선을 만들었다.
- 벽과 기믹을 놓고, 8방향 발도를 무작위로 이어 기준 경로를 만든 뒤 **그 경로가 지나는 칸에만 몬스터를 배치**한다.
- 기준 경로로 다시 재생해 살아남는 특수 몬스터는 일반 몬스터로 바꾸고, **솔버로 실제 최소 발도 횟수를 구해** 목표보다 너무 쉬운 배치는 버린다.
- 허용 발도 횟수는 최소값에 여유 1회를 더하고, 10층마다는 여유 없이 딱 맞춘다. 층마다 시드를 바꿔 최대 200번까지 다시 시도한다.
- 중갑(16층), 방패(28층), 충전(36층), 이동형(45층), 포탈(55층), 대형(64층), 버튼·폭탄(72층), 거울(80층) 순서로 새 요소를 소개하고, 소개 구간에서는 다른 기믹과 겹치지 않게 해 규칙이 또렷이 보이게 했다.

**사용 기술**: Procedural Generation, Seeded Random, Editor 도구

### IDDFS 최소 풀이 솔버

반복 심화 깊이 우선 탐색으로 층의 최소 발도 횟수와 그 순서를 찾는다.

**동작 방식**

- 깊이를 1회씩 늘려 가며 탐색하므로 처음 찾은 답이 곧 **최소 발도 횟수**다.
- 한 상태에서 모든 방향을 먼저 시뮬레이션해 바로 끝나는 수가 있으면 즉시 답으로 쓰고, 나머지는 **많이 베는 수부터** 파고든다.
- 한 번의 발도로 줄 수 있는 최대 피해량으로 남은 체력을 나눠, 남은 횟수로 절대 깰 수 없는 가지를 잘라낸다.
- 이미 풀 수 없다고 증명된 상태를 상태 키로 기억해 다시 탐색하지 않고, 노드 예산을 넘으면 '판정 불가'로 구분해 멈춘다.

**사용 기술**: IDDFS, 가지치기 (Pruning), 메모이제이션

### 지금 상태에서 다시 푸는 힌트

힌트는 미리 저장한 정답이 아니라, 플레이어가 지금까지 둔 수를 반영해 그 자리에서 다시 푼다.

**동작 방식**

- 현재 상태에서 솔버를 돌려 다음 발도 방향과 '남은 발도 N회로 클리어 가능' 정보를 보여 주고, 경로를 금색으로 미리 그린다.
- **광고를 보여 주기 전에 먼저 풀어 보고**, 풀 수 없는 상태면 광고를 띄우지 않는다.
- 광고 전후로 상태가 바뀌었는지 확인해, 바뀌었으면 다시 풀어서 틀린 힌트를 주지 않는다.

- 이미지: https://human.minyee2913.net/img/games/baldo/2.jpg (힌트 표시: '오른쪽으로 발도해보세요. (남은 발도 5회로 클리어 가능)')

### 타격감 연출

짧은 퍼즐 한 수에도 손맛이 느껴지도록 베기 순간을 강조했다.

**동작 방식**

- 처치 수에 비례해 길어지는 히트스톱(기본 0.035초 + 처치당 0.028초, 최대 0.16초)을 넣었다.
- 픽셀 단위로 맞춘 화면 흔들림, 돌진 전 예비 동작과 잔상, 칼날 궤적·불꽃·충격 링·폭발 섬광·파편을 풀링해서 재사용한다.
- Android 진동으로 상황별 짧은 피드백(20~60ms)을 준다.

**사용 기술**: Hit-stop, Object Pooling, Pixel Perfect Camera

- 이미지: https://human.minyee2913.net/img/games/baldo/aim.jpg (대각선 조준 미리보기 (점선이 돌진 경로))

### 출시와 운영 기능

Google Play 출시에 필요한 광고·저장·설정·현지화를 갖췄다.

**동작 방식**

- 힌트는 보상형 광고, 20층마다 클리어 후 전면 광고(준비되지 않았으면 건너뜀)를 보여 준다.
- 진행 상황은 JSON으로 저장하되 임시 파일과 백업 파일을 거쳐 써서 저장 중 손상을 막는다. 층별 최소 발도 기록, 클리어 횟수, 힌트 사용 여부를 남긴다.
- 기기 언어에 따라 한국어·영어를 고르고, 음악·효과음 볼륨과 진동을 설정할 수 있다.
- Android 대상 API 36으로 빌드한다.

**사용 기술**: AdMob, JSON 저장, 현지화

- 이미지: https://human.minyee2913.net/img/games/baldo/settings.jpg (설정 화면 (음악·효과음·진동·언어))

## 기술적 문제 해결

### 1000개 층이 모두 풀린다는 보장 [해결]

- 문제 상황: 층을 자동으로 1000개 만들면, 사람이 하나하나 풀어 보지 않고도 모든 층이 정해진 횟수 안에 풀린다는 것을 보장해야 했다.
- 해결 과정:
  - 생성 단계에서 모든 층을 솔버로 풀어 최소 발도 횟수를 구하고, 허용 횟수를 그 값에 맞춰 정했다.
  - 에디터에 층 검증 창을 만들어 데이터 오류와 풀이 가능 여부를 확인한다.
  - 자동 테스트에서 층을 표본으로 골라 솔버가 찾은 답을 실제 게임 세션에 그대로 재생해 클리어되는지 확인한다.
- 적용한 기술 / 접근: IDDFS 솔버, NUnit 테스트, Editor 검증 도구
- 결과: 규칙 테스트·기믹 테스트·솔버 일치 테스트·광고 흐름 테스트 등 29개 테스트 케이스로 규칙과 생성 결과를 검증한다.

### 광고를 봤는데 힌트를 줄 수 없는 상황 [해결]

- 문제 상황: 보상형 광고를 다 본 뒤에야 풀 수 없는 상태라는 걸 알게 되거나, 광고를 보는 사이 상태가 바뀌어 틀린 힌트를 줄 위험이 있었다.
- 해결 과정:
  - 광고를 띄우기 전에 현재 상태에서 먼저 풀이를 계산하고, 답이 없으면 광고를 띄우지 않는다.
  - 광고 전에 상태 서명을 저장해 두고 광고 후 비교해, 달라졌으면 다시 푼다.
- 결과: 광고를 본 플레이어는 항상 지금 상태에 맞는 힌트를 받는다.
