# 도장을 지켜라!

> 2라운드부터 배경의 보스가 끼어드는 1:1 대전 격투 게임 (3인 팀)

두 플레이어가 도장에서 맞붙는 대전 격투 게임. 2라운드부터는 배경에 있던 보스가 전투에 끼어들어, 상대와 보스를 동시에 상대해야 한다.

- 페이지: https://human.minyee2913.net/projects/protect-dojo
- 카테고리: 게임 개발
- 개발 기간: 2023
- 개발 상태: 개발 완료
- 플랫폼: PC
- 장르: 대전, 액션, 격투
- 팀 구성: 3인 팀 (개발 2인, 아트 1인)
- 담당 역할: 플레이어, 방 시스템, UI 디자인
- 기여도: 50%
- 게임 엔진: Unity
- 사용 언어: C#

## 프로젝트 소개

두 플레이어가 맞붙는 대전 격투 게임인데, **2라운드부터 배경에 있던 보스가 전투에 끼어들어** 상대와 보스를 함께 신경 써야 한다.

개발 2명·아트 1명 팀에서 **플레이어, 방 시스템, UI 디자인**을 맡았다 (기여도 50%).
