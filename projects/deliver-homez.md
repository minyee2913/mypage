# 구해줘 홈즈 김배달의 우당탕탕 대모험

> 던져라, 배달부!

> 점프 대신 드래그로 몸을 던지는 3분 배달 플랫포머 (5인 팀, 팀장)

점프 버튼 대신 마우스 드래그로 캐릭터를 던지는 방식으로 진행되는 아케이드 플랫포머 게임.

- 페이지: https://human.minyee2913.net/projects/deliver-homez
- 카테고리: 게임 개발
- 개발 기간: 2024.07 ~ 2024.09
- 개발 상태: 개발 완료
- 플랫폼: PC
- 장르: 아케이드, 플랫포머
- 팀 구성: 5인 팀 (개발 4인, 아트 1인)
- 담당 역할: 팀장, UI·시스템 개발, 배달·점수·보급 흐름, 아이템 효과 시스템, 오프닝 연출, 랭킹·결과 화면
- 기여도: 60% (커밋 81개 중 43개)
- 게임 엔진: Unity 2022.3
- 사용 언어: C#
- 프레임워크 / 라이브러리: Cinemachine, LeanTween, TextMeshPro
- 주요 기술: Rigidbody2D 임펄스, 포물선 궤적 예측, Tilemap, PlayerPrefs 랭킹, 코루틴 컷신

## 프로젝트 소개

월세 납부일이 다가온 피자 배달부 김배달 씨가 배달 단가가 높은 협곡 마을에서 배달하는 이야기다.

선린인터넷고 게임 동아리 C,Real에서 5인 팀(개발 4·아트 1)으로 만들었고, **팀장이자 UI·시스템 개발**을 맡았다.

점프 버튼이 없다. 마우스를 끌어 당긴 방향과 세기로 김배달 씨를 던지고, 거칠게 착지하면 피자를 떨어뜨린다. **조작 자체가 웃음 포인트가 되도록** 설계한 아케이드 게임이다.

### 주요 특징

- 5인 팀(개발 4·아트 1)의 **팀장**, UI·시스템 개발
- 드래그 세기·방향으로 던지는 **포물선 궤적 점프**
- 제한 시간 3분 동안 **배달·점수·보급** 루프
- 아이템 버프·디버프를 공통 **Effect 클래스**로 구조화
- 이름 기반 **로컬 랭킹**과 결과 화면

## 게임 플레이

- A·D로 걷고, 땅에 서 있을 때 마우스 왼쪽 버튼이나 Space를 누른 채 끌었다 놓으면 당긴 반대 방향으로 몸을 던진다. 당긴 거리가 짧으면 점프하지 않는다.
- 날아가는 동안 A·D로 방향을 더해 더 멀리 갈 수 있다. 점프 직후 바로 누르면 '초가속' 문구가 뜬다.
- 피자 가게에서 피자 3판을 받아 화살표가 가리키는 배달지에 착지하면 배달 성공이다. 다음 배달지는 무작위로 정해진다.
- 높은 곳에서 세게 떨어지면 들고 있던 피자를 한 판 떨어뜨린다. 떨어진 피자는 다시 주울 수 있다.
- 피자가 떨어지면 가게로 돌아가 다시 받고, 이때 남은 시간이 40초 늘어난다. 제한 시간 3분이 끝나면 점수와 순위가 나온다.
- 맵 곳곳의 아이템 상자는 속도 증가·속도 감소·점프 강화·좌우 반전 중 하나를 10초 동안 건다.

## 핵심 구현 기능

### 드래그로 던지는 포물선 점프

당긴 거리와 방향이 곧 점프 세기와 방향이 되는, 이 게임의 핵심 조작.

**구현 목적**: 점프 버튼 하나로 끝나는 플랫포머 대신, 힘 조절에 실패하는 것까지 재미가 되는 조작을 만들고 싶었다.

**동작 방식**

- 누른 지점과 현재 커서 사이의 거리를 최대값으로 자르고, 반대 방향 벡터에 곱해 던질 힘을 구한다.
- 끄는 동안 **15개 점으로 포물선 궤적을 미리 보여 준다**. 시간 간격마다 위치 = 시작점 + 힘×t − ½·g·t² 로 계산한다.
- 많이 당길수록 카메라가 조금씩 확대되고, 놓으면 원래대로 돌아와 힘을 모으는 느낌을 준다.
- 놓을 때 Rigidbody2D에 임펄스로 힘을 주고, 당긴 거리가 최대의 20% 이하이면 점프를 취소한다.
- 점프 직후 0.2초 안에 방향키를 누르면 '초가속' 문구를 띄워 숨은 조작을 알려 준다.

**사용 기술**: Rigidbody2D, ForceMode2D.Impulse, Cinemachine

### 배달·점수·보급 루프

3분 안에 최대한 많이, 최대한 빨리 배달하게 만드는 게임 흐름.

**동작 방식**

- 배달지마다 가게에서 떨어진 거리에 비례해 기본 점수를 주고, 직전 배달 이후 걸린 시간만큼 깎는다. 성공한 배달마다 30점을 더한다.
- 모든 배달지를 한 번씩 돌면 목록을 다시 채우고, 남은 곳 중 하나를 무작위로 켠다.
- 피자를 다 쓰면 목표가 가게로 바뀌고, 가게에 착지하면 컷신과 함께 피자 3판과 추가 시간 40초를 준다.
- 세게 착지하면(세로 충돌 속도 기준) 피자를 떨어뜨리고, 남은 개수에 따라 다른 말풍선 대사를 띄운다.
- 60초 동안 아무 조작이 없으면 경고 후 시작 화면으로 돌아간다.

### 화면 밖 목표를 가리키는 화살표

배달지가 화면 밖에 있으면 화면 가장자리에 방향 화살표를 띄우고, 화면 안이면 목표 위에 표시한다.

**동작 방식**

- 플레이어에서 목표로 향하는 각도를 화면 대각선 각도와 비교해 위·아래·왼쪽·오른쪽 중 어느 가장자리에 붙일지 정한다.
- 가장자리 안에서의 위치는 비례식으로 구하고, 화면 밖으로 넘어가지 않게 잘라 낸다.
- HUD에 목표까지 남은 거리(m)를 함께 보여 준다.

### 아이템 효과 시스템

버프·디버프를 공통 Effect 추상 클래스로 묶어, 새 효과를 클래스 하나로 추가할 수 있게 했다.

**동작 방식**

- Effect는 지속 시간과 경과 시간을 관리하고, 시작·종료 시 하위 클래스의 OnStart·OnEnd를 부른다.
- 효과마다 HUD 아이콘을 만들어 남은 시간을 원형 게이지로 보여 주고, 캐릭터 색으로도 상태를 알린다.
- 속도 증가(1.3배)·감소(0.5배), 점프 강화(최대 당김 거리 1.3배), 좌우 반전 효과를 구현했다. 좌우 반전은 이동 방향과 스프라이트 방향을 함께 뒤집는다.
- 같은 효과를 다시 얻으면 기존 효과를 끝내고 지속 시간을 더한 새 효과로 바꾼다.

**사용 기술**: 추상 클래스, Image.fillAmount

- 이미지: https://human.minyee2913.net/img/games/deliver-homez/tuto-air.jpg (튜토리얼: 점프 중 방향키 입력)

### 오프닝 컷신과 말풍선

**동작 방식**

- 게임 시작 시 코루틴으로 카메라 확대, 피자가 하나씩 떨어지는 연출, 무작위 대사, 튜토리얼, 'GO! GO!'를 순서대로 진행한다.
- 캐릭터 머리 위 말풍선이 몇 초 뒤 서서히 사라지고, 캐릭터가 돌아서도 글자가 뒤집히지 않게 했다.

**사용 기술**: Coroutine, LeanTween

### 이름 기반 랭킹과 결과 화면

**동작 방식**

- 시작할 때 이름을 입력받고, 게임이 끝나면 같은 이름의 기록이 있으면 최고 점수만 갱신하고 없으면 새로 추가한다.
- 랭킹은 PlayerPrefs에 저장하고, 결과 화면에서 배달 수·점수·내 최고 기록·현재 순위와 '신기록!'·'첫기록!' 문구를 보여 준다.

**사용 기술**: PlayerPrefs

## 기술적 문제 해결

### 같은 이름으로 다시 하면 랭킹이 갱신되지 않고 중복되던 문제 [해결]

- 문제 상황: 같은 이름으로 여러 번 플레이하면 기록이 줄마다 새로 쌓여, 한 사람이 랭킹을 여러 칸 차지했다.
- 원인 분석: 게임이 끝날 때마다 무조건 새 기록을 추가했고, 기록 타입이 값 타입(struct)이라 찾아낸 기록을 고쳐도 목록 안의 원본이 바뀌지 않았다.
- 해결 과정:
  - 기록 타입을 참조 타입(class)으로 바꿔 찾은 기록을 직접 고칠 수 있게 했다.
  - 같은 이름이 있으면 점수가 더 높을 때만 점수와 배달 수를 갱신하고, 없을 때만 새로 추가하게 바꿨다.
- 결과: 이름마다 최고 기록 한 줄만 남고, 결과 화면에서 신기록과 첫 기록을 구분해 보여 줄 수 있게 되었다.

### 같은 아이템을 연속으로 먹으면 오류가 나던 문제 [해결]

- 문제 상황: 효과가 남아 있는 상태에서 같은 아이템을 또 먹으면 오류가 발생했다.
- 원인 분석: 기존 효과를 새 효과로 바꿀 때 HUD 아이콘을 먼저 지웠는데, 기존 효과의 갱신·종료 처리가 이미 지워진 아이콘에 다시 접근했다.
- 해결 과정:
  - 아이콘을 지운 뒤 참조를 비우고, 갱신·종료 처리에서는 아이콘이 남아 있을 때만 접근하도록 고쳤다.
- 결과: 같은 효과를 이어서 얻어도 오류 없이 새 효과로 교체된다.
