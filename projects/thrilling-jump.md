# 스릴있는 점프게임

> 공중에서 적을 내리찍어 처치하는 점프 액션 (동아리 1학년 제작)

공중으로 뛰어올라 적을 내리찍어 처치하는 2D 점프 액션 게임. 동아리 1학년 때 만들었다.

- 페이지: https://human.minyee2913.net/projects/thrilling-jump
- 카테고리: 게임 개발
- 개발 기간: 2023
- 개발 상태: 개발 완료
- 플랫폼: PC
- 장르: 점프, 액션
- 담당 역할: 플레이어, 전투 시스템
- 기여도: 70%
- 게임 엔진: Unity
- 사용 언어: C#

## 프로젝트 소개

공중에서 **적을 내리찍어 처치하는** 점프 액션 게임이다. 동아리 1학년 때 만들었고, **플레이어와 전투 시스템**을 맡았다 (기여도 70%).
