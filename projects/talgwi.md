# 탈귀

> 한밤중 학교에서 낮이 될 때까지 귀신을 피해 도망치는 공포 생존 게임 (선린톤 10th)

놓고 온 물건을 찾으러 밤의 학교에 온 학생이 복도에서 귀신을 만나, 낮이 될 때까지 손전등에 의지해 도망치는 2D 공포 생존 게임.

- 페이지: https://human.minyee2913.net/projects/talgwi
- 카테고리: 게임 개발
- 개발 기간: 2024
- 개발 상태: 개발 완료
- 플랫폼: PC
- 장르: 공포, 생존
- 팀 구성: 4인 팀 (개발 2인, 아트 2인)
- 담당 역할: 플레이어, 손전등, 맵 기믹
- 기여도: 30%
- 게임 엔진: Unity
- 사용 언어: C#

## 프로젝트 소개

선린톤 10th에서 개발 2명·아트 2명 팀으로 만들었다. 놓고 온 물건을 찾으러 한밤중 학교에 온 학생이 복도에서 귀신을 만나고, **낮이 될 때까지 살아남아야** 한다.

**플레이어, 손전등, 맵 기믹**을 맡았다 (기여도 30%).
