# 버튼을 눌렀더니 판타지 게임속 주인공이 되어버린 건에 대하여

이전 회차 플레이어의 행동이 그림자가 되어 다음 플레이에 영향을 주는 다회차 기반 로그라이크 액션 게임.

- 페이지: https://human.minyee2913.net/projects/isekai-button
- 카테고리: 게임 개발
- 개발 기간: 2024
- 플랫폼: PC
- 장르: 로그라이크, 액션
- 팀 구성: 4인 팀 (개발 3인, 아트 1인)
- 담당 역할: 전투 시스템, 플레이어, 무기 시스템, 몬스터
- 기여도: 50%
- 게임 엔진: Unity
- 사용 언어: C#

## 프로젝트 소개

버튼을 누르면 다른 세상에서 5억 년을 살고 기억을 잃은 채 돌아와 돈을 받는다는 제안을 받아들인 소녀가, 판타지 세계에서 5억 년 동안 던전을 도는 이야기다.

## 게임 플레이

- 게임 시작 시 앞에 무기가 떨어져 있다.
- 좌클릭을 홀드하면 공격 범위가 보이고 놓으면 공격한다.
- 숫자 키로 스킬을 사용한다.
