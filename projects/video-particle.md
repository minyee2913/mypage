# Video Particle

영상 파일 데이터를 추출해서 마인크래프트 내 파티클로 영상을 그대로 구현하고 재생하는 외부 프로그램.

- 페이지: https://human.minyee2913.net/projects/video-particle
- 카테고리: 마인크래프트 개발
- 개발 기간: 2023
- 플랫폼: STANDALONE PROGRAM
- 사용 언어: TypeScript
- 프레임워크 / 라이브러리: Node.js, fluent-ffmpeg (영상 프레임 추출), Jimp (이미지 픽셀 읽기)
