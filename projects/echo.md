# ECHO

집에 들어온 NPC들이 벌이는 돌발 행동을 아이템으로 막아내는 아케이드 시뮬레이션 전략 게임.

- 페이지: https://human.minyee2913.net/projects/echo
- 카테고리: 게임 개발
- 개발 기간: 2024
- 플랫폼: PC
- 장르: 아케이드, 시뮬레이션, 전략
- 팀 구성: 3인 팀 (개발 3인)
- 담당 역할: 상호작용 시스템, 아이템 시스템
- 기여도: 60%
- 게임 엔진: Unity
- 사용 언어: C#

## 프로젝트 소개

복지센터를 연 플레이어가 찾아오는 진상 NPC들의 돌발 행동을 아이템으로 막아내는 게임이다.
