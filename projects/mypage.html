> ABOUT 프로젝트 소개

직접 만든 게임을 게시하려고 2024년에 만든 사이트다. 처음엔 내용을 많이 채우지 못했고, 이후 프로젝트마다 공식 사이트 같은 상세 페이지와 크롤러·AI 접근성을 갖추도록 다시 만들었다.

모든 프로젝트 정보는 TypeScript 데이터 파일 하나에서 나온다. 같은 데이터로 화면, 정적 HTML, 메타 태그와 구조화 데이터(JSON-LD), sitemap.xml, llms.txt, projects.json, 프로젝트별 Markdown을 만들어 내용이 서로 어긋나지 않는다.

> FEATURES 핵심 구현 기능

빌드 타임 정적 생성

동작 방식
  • 빌드 마지막 단계에서 앱을 서버 렌더링(renderToString)해 페이지마다 완성된 HTML을 쓴다. 브라우저에서는 그 위에서 앱이 다시 시작된다.
  • 봇에게만 다른 내용을 주지 않고, 사람과 크롤러가 같은 HTML을 받는다.
  • 빌드할 때 데이터 형식을 검사하고, 공개 산출물에 비밀값처럼 보이는 문자열이 섞였으면 빌드를 멈춘다.
  • 배포 전후로 모든 페이지의 상태 코드, 제목, 핵심 문구, 이미지 응답을 HTTP로 확인하는 검증 스크립트를 돌린다.

게임별 진입 연출과 효과음

동작 방식
  • 상세 페이지를 열 때 게임마다 다른 연출이 화면을 걷어 낸다. 발도 일섬, 불타는 종이, 깨지는 유리, 피자 상자 던지기 등을 Canvas 2D로 그린다.
  • 효과음은 음원 파일 없이 Web Audio로 합성한다. 16비트 게임기처럼 펄스파·FM 음색을 32kHz로 계산하고, 연출의 충돌 순간에 맞춰 재생한다. 기본은 꺼져 있다.
  • 동작 줄이기 설정을 켠 사용자에게는 연출을 건너뛴다.
