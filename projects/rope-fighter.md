# 로프앤파이터

> 발차기와 로프 액션을 이어 붙이는 플랫포머 액션 (4인 팀)

발차기 공격과 로프 액션을 연계해 화려하게 싸우는 2D 플랫포머 액션 게임.

- 페이지: https://human.minyee2913.net/projects/rope-fighter
- 카테고리: 게임 개발
- 개발 기간: 2023
- 개발 상태: 개발 완료
- 플랫폼: PC
- 장르: 플랫포머, 액션
- 팀 구성: 4인 팀 (개발 2인, 아트 2인)
- 담당 역할: 플레이어, 전투 시스템, 밧줄 시스템
- 기여도: 60%
- 게임 엔진: Unity
- 사용 언어: C#

## 프로젝트 소개

발차기 공격과 **로프 액션을 연계하는 화려한 전투**가 특징인 플랫포머 액션 게임이다.

개발 2명·아트 2명 팀에서 **플레이어, 전투 시스템, 밧줄 시스템**을 맡았다 (기여도 60%).
