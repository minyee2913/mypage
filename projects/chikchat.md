# ChikChat

> 과제로 만든 PC용 실시간 채팅 앱

실시간 채팅, 회원 관리, 로그인·회원가입, 시스템 트레이 최소화를 지원하는 PC용 채팅 앱. 과제로 만들었다.

- 페이지: https://human.minyee2913.net/projects/chikchat
- 카테고리: 프로그램 개발
- 개발 기간: 2023.11
- 개발 상태: 개발 완료
- 플랫폼: PC (데스크톱 앱)
- 사용 언어: JavaScript

## 프로젝트 소개

과제로 만든 PC용 채팅 앱이다. 실시간 채팅과 회원 관리, 로그인·회원가입을 지원하고, 시스템 트레이로 최소화할 수 있다.

## 핵심 구현 기능

### 주요 기능

**동작 방식**

- 실시간 채팅
- 회원 관리, 로그인·회원가입
- 시스템 트레이 최소화
