minyee2913 (이강민) · Unity·C# 게임 클라이언트 개발자

2019년 마인크래프트 맵 제작으로 개발을 시작했고, 2020년부터 Minecraft Bedrock RPG 서버 Luminous Wanderlust를 지금까지 만들고 있습니다.

선린인터넷고등학교에서 대회·해커톤·동아리 프로젝트로 Unity 게임을 꾸준히 만들었고, 지금은 KAIST 새내기과정학부에 다니며 1인 팀 네로폰으로 로그라이크 덱빌딩 액션 RPG IGNOTUS를 개발하고 있습니다 (2027년 상반기 출시 목표).

액션 전투와 멀티플레이(LAN·전용 서버·Steam P2P, Photon)부터 모바일 출시, 게임 서버 개발까지 직접 다뤄 왔습니다.

2026년부터는 Claude Code 같은 AI 코딩 에이전트를 실제 개발에 깊게 쓰고 있습니다. 발!도!!는 바이브 코딩으로 Google Play 출시까지 했고, 에디터와 서버에 에이전트를 직접 연결하고 에이전트가 지킬 작업 규칙과 반복 작업용 스킬을 만들어 혼자서도 큰 프로젝트를 진행합니다.

게임 개발

  • IGNOTUS — 실시간 액션과 전략적인 타일 전투가 결합된 로그라이크 덱빌딩 액션 RPG. 전투 도중 시간을 멈추고 [영역]을 전개해 스킬을 타일에 배치한다. PC(Steam)와 모바일로 2027년 상반기 출시 예정.
  • 발!도!! — 검을 발도하면 그 방향 끝까지 돌진하며 스친 적을 모두 벤다. 정해진 발도 횟수 안에 층의 모든 적을 처치하며 지하 1000층까지 내려가는 모바일 액션 퍼즐 게임.
  • 루미너스 런처 — Minecraft Bedrock RPG 서버 Luminous를 위해 Godot 4(.NET)로 직접 만든 전용 게임 클라이언트. 블록 월드 렌더링, 엔티티 모델·애니메이션, 서버 UI, Xbox 로그인, 설치 파일까지 갖춰 Windows·macOS·Android에서 마인크래프트 없이 바로 접속한다.
  • 제발 꺼져 용사야! — 마왕이 되어 카드 덱으로 몬스터를 소환하고, 마을을 점령해 보급선을 넓히며 끝없이 강해지는 용사로부터 마왕성을 지키는 모바일 역 타워 디펜스 게임.
  • 하늘오름 — 멈추지 않는 캐릭터가 적과 발판을 베어 생기는 반동만으로 우주까지 올라가는 2D 원버튼 스코어 어택 게임.
  • 내가 찻잔이라니! — 어느 날 찻잔이 되어 버린 주인공이 3D 카페 안을 뛰어다니며 재료를 모아 음료를 완성하고, 시간 안에 손님의 주문을 처리하는 2.5D 액션 게임.
  • 생존 전략! — 모션 그래픽을 이용한 스토리 전개와 플레이어의 행동이 다음 회차 스탯에 반영되는 액션 게임.
  • Albedo — 빛 효과로 스타일을 강조하고, 플레이어가 직접 스킬을 쓰지 않고 다른 주체에게 맡기는 방식으로 전투가 진행되는 탈출 액션 게임.
  • 고아의 공장 — 부도 직전의 부모님 공장을 물려받은 주인공이 되어, 박스를 주문하고 컨베이어로 오는 물품을 포장해 출고하는 아케이드 게임. 다른 공장 게임과 달리 모든 일을 캐릭터가 직접 움직여서 한다.
  • KOROSHITE — 서로 다른 스킬을 가진 캐릭터로 8인 대전과 보스전을 즐길 수 있는 PC 액션 게임.
  • Hunger of War — 3차 세계대전 뒤 식량 보급이 끊긴 마을들이 서로의 식량을 빼앗아 자기 마을 주민을 살리는 PC 멀티플레이 생존 대전 게임.
  • 탈귀 — 놓고 온 물건을 찾으러 밤의 학교에 온 학생이 복도에서 귀신을 만나, 낮이 될 때까지 손전등에 의지해 도망치는 2D 공포 생존 게임.
  • 버튼을 눌렀더니 판타지 게임속 주인공이 되어버린 건에 대하여 — 이전 회차 플레이어의 행동이 그림자가 되어 다음 플레이에 영향을 주는 다회차 기반 로그라이크 액션 게임.
  • 구해줘 홈즈 김배달의 우당탕탕 대모험 — 점프 버튼 대신 마우스 드래그로 캐릭터를 던지는 방식으로 진행되는 아케이드 플랫포머 게임.
  • ECHO — 집에 들어온 NPC들이 벌이는 돌발 행동을 아이템으로 막아내는 아케이드 시뮬레이션 전략 게임.
  • 범근러쉬 — 학교 친구를 등장인물로 내세운 엽기적인 감성의 러닝 아케이드 게임.
  • ESCAPE THE MUSIC — 노트 상호작용에 따라 뒤의 플랫포머 캐릭터가 반응하는 구조의 플랫포머 리듬 게임.
  • 유클리우드 Edge — 전투마다 두더지 잡기 같은 퍼즐을 진행하고, 퍼즐 성취도에 따른 버프를 받은 뒤 실시간 전투가 이어지는 퍼즐 액션 로그라이크.
  • 도장을 지켜라! — 두 플레이어가 도장에서 맞붙는 대전 격투 게임. 2라운드부터는 배경에 있던 보스가 전투에 끼어들어, 상대와 보스를 동시에 상대해야 한다.
  • 로프앤파이터 — 발차기 공격과 로프 액션을 연계해 화려하게 싸우는 2D 플랫포머 액션 게임.
  • 스릴있는 점프게임 — 공중으로 뛰어올라 적을 내리찍어 처치하는 2D 점프 액션 게임. 동아리 1학년 때 만들었다.
  • 파머의 해피 라이프 — 오염되어 가는 타일을 빠르게 이동하며 중화시켜 땅을 지키는 아케이드 퍼즐 게임.

마인크래프트 개발

  • Luminous Wanderlust — 유물·장비·직업 특성을 조합해 나만의 전투 스타일을 만드는 반오픈월드 액션 RPG. Go 기반 서버 엔진 Dragonfly를 포크해 게임 서버와 전용 클라이언트, 게이트웨이까지 직접 개발하고 운영한다.
  • 마인크래프트에서 만나는 제주바다 — 한국해양과학기술원 제주연구소의 '찾아가는 해양과학교실'에서 쓰는 Minecraft Bedrock 교육 콘텐츠. 조간대 생물 채집, 생물 도감, 배양 실험 미니게임을 Script API로 개발하고 기존 기능을 유지보수했다.
  • Valorant Addon — 마인크래프트에서 발로란트의 캐릭터와 총기 시스템을 구현한 마인크래프트 BE 애드온 프로젝트.
  • Video Particle — 영상 파일 데이터를 추출해서 마인크래프트 내 파티클로 영상을 그대로 구현하고 재생하는 외부 프로그램.
  • Block Beat — 키 입력이 아닌 마우스로 에임을 돌려 노트를 치는 마인크래프트 BE 맵 기반 리듬게임.

프로그램 개발

  • UnityUtils — Unity 개발을 간소화하려고 만든 C# 공용 모듈 모음. 체력·스탯·버프·카메라 연출·사운드·데미지 표시 등을 IGNOTUS, 생존 전략! 등 여러 게임에서 함께 쓴다.
  • myPage (이 포트폴리오 사이트) — 지금 보고 있는 포트폴리오 사이트. React로 만들고 빌드할 때 모든 페이지를 정적 HTML로 미리 그려, JavaScript 없이도 내용이 보이고 검색엔진과 AI가 읽을 수 있게 했다.
  • mcCmd — 마인크래프트 명령어처럼 생긴 문법으로 코딩해 보고 싶어서 만든 스크립트 언어. C++로 토큰 분해부터 스코프와 함수 호출까지 인터프리터를 직접 구현했다.
  • 2913SimpleDB — 클래스 필드에 데코레이터를 붙이면 SQLite 테이블과 쿼리가 만들어지는 TypeScript 데이터베이스 패키지. 마인크래프트 서버 프레임워크 BDSX에서 쓰려고 만들어 npm에 공개했다.
  • ChikChat — 실시간 채팅, 회원 관리, 로그인·회원가입, 시스템 트레이 최소화를 지원하는 PC용 채팅 앱. 과제로 만들었다.
